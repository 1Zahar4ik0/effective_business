# Что осталось для реального запуска — 20.09.2026

## Токен уже на месте

`MAX_BOT_TOKEN` найден приложением в локальном окружении. Повторно присылать его не нужно.
По вашему указанию он хранится только на этом компьютере и передаётся только официальному
API `https://platform-api2.max.ru` в заголовке Authorization. Не копируйте `.env` на хостинг,
в переписку или комплект сдачи. Публичное размещение пока не выполнялось.

## 1. Исправить доверие к сертификату MAX

Выполненная проверка обнаружила TLS-ошибку: `unable to get local issuer certificate`,
код 20. Это не доказательство неправильного токена: до успешной проверки TLS
действительность токена установить нельзя. `verify=False` не используется.

1. Откройте официальную [страницу сертификатов Госуслуг](https://www.gosuslugi.ru/crt).
2. Получите оттуда актуальную цепочку сертификатов для Linux/PEM. Не используйте
   файлы из случайных инструкций и не присылайте приватный ключ.
3. Сохраните файлы на компьютере и сообщите **только их локальные пути и адрес источника**.
   После проверки файлов я подготовлю CA bundle и подключу его только к клиенту MAX.
   Установка доверия во всю Windows для проекта не требуется.

Для уже проверенного полного PEM bundle предусмотрен `compose.local-max-ca.yaml`.
В локальном `.env` указывают `MAX_CA_BUNDLE_HOST=C:/путь/ca-bundle.pem`, затем:

```powershell
cd C:\EffectiveBusiness
docker compose -f compose.yaml -f compose.local-max-ca.yaml up -d --wait
docker compose -f compose.yaml -f compose.local-max-ca.yaml exec -T app python backend/max_preflight.py
```

Этот способ ещё не проверен на настоящем bundle: файл пока не предоставлен.
Проверка выводит только статусы; она не регистрирует webhook и не отправляет сообщения.

## 2. Указать публичную ссылку бота

Пришлите обычную ссылку вида `https://max.ru/…` на вашего бота и подтвердите,
что можете менять настройки бота и мини-приложения в MAX для бизнеса.
Секреты, данные запуска `initData` и снимки экрана с токеном не нужны.

После реального входа нужно назначить одного редактора по MAX ID.
ID и секрет webhook сохраняются локально в `MAX_ADMIN_IDS` и `MAX_WEBHOOK_SECRET`.
Секрет webhook я могу сгенерировать локально без вывода в чат.

## 3. Выбрать способ HTTPS-доступа

С текущим ограничением «токен только локально» весь сервер приложения, проверяющий
подпись MAX, должен остаться на вашем компьютере. Для временной проверки подходит
HTTPS-туннель к отдельному локальному рабочему окружению. Компьютер и Docker должны
быть включены. Публиковать общий демонстрационный вход с правами редактора нельзя.

Если выбираете этот путь, напишите: **«Разрешаю временный HTTPS-доступ через туннель
к отдельному локальному рабочему окружению; токен остаётся на моём компьютере»**.
После выбора провайдера и допустимого адреса я подготовлю окружение и выполню
подключение в разрешённых вами пределах. Пока туннель не создавался.

Удалённый сервер требует отдельного решения о месте хранения токена: текущего
разрешения на его перенос нет. Покупать VPS только ради текущей проверки не нужно.

После появления HTTPS-адреса нужно указать адрес мини-приложения в настройках MAX.
В локальном окружении заполняются `PUBLIC_ORIGIN`, `MAX_APP_URL`, `MAX_WEBHOOK_SECRET`.
`MAX_APP_URL` — ссылка запуска в MAX; её нельзя подменять адресом localhost.

## 4. Данные поддержки

В продукт добавлены 10 официальных объявлений с проверенными суммами и сроками.
Они доступны в разделе «Каталог поддержки → Реальные объявления» без входа.
Это не 10 полностью опубликованных правил персонального подбора: нормативные
редакции и текущие карточки портала ещё проверяются. Учебный подбор отделён.

Если у вас открывается [Электронный бюджет](https://promote.budget.gov.ru/),
пришлите публичные ссылки или выгруженные публичные карточки трёх приоритетных отборов:

- развитие фермерского хозяйства: `26-009-R0165-1-0135`;
- «Агромотиватор»: `26-009-R0166-1-0134`;
- «Агропрогресс»: `26-009-R0164-1-0133`.

Нужны текущий статус, изменения, даты и приложения. Пароль Госуслуг и доступ
к личному кабинету не нужны. В этой среде портал не загрузился; это не основание
называть приём открытым. Остальная сверка нормативных актов — моя работа,
а не требование к вам самостоятельно заполнять каталог.

## 5. Реальная проверка на телефоне

Когда HTTPS и MAX будут подключены: открыть бота → мини-приложение → сохранить
анкету → открыть карточку → сохранить план → отметить документ → закрыть и
повторно открыть. Проверить сохранение, а затем официальный маршрут, без подачи заявки.

Сообщите модель/ОС телефона, версию MAX, какие шаги прошли и текст ошибки, если она есть.
Для этого подготовлен `docs/MAX-DEVICE-REPORT.md`. Аналогичный проход нужен в веб-MAX.
На 20.09.2026 оба реальных сценария не проверены; браузерная проверка их не заменяет.
