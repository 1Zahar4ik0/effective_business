## Архив и доступ

Архив: `data/official/sources/catalog-20260928/`. `retrieval.jsonl` содержит URL, фактическую дату/время UTC, код HTTP, результат curl, размер и SHA-256. Неудачные обращения сохранены без присвоения даты содержательной проверки. `extracted-index.json` связывает извлечённые PDF с ZIP и именами оригинальных файлов; `SHA256SUMS.txt` фиксирует файлы исследования. `readiness.json` — машиночитаемая передача блокировок.

Использован обычный публичный доступ с локального компьютера, без авторизации, CAPTCHA, cookies, обходов и отключения TLS. VPS не использовался. Успешное получение карточек не делает публичные маршруты стабильным API. Массовое обновление не автоматизировано. После получения JSON запросы PDF портала и новых карточек завершались тайм-аутами; повторные попытки трёх PDF с лимитом 50 секунд также не дали документа.
