## Проверка правил

- Исполняемые ограничения имеют `source_ref`. Для «Агропрогресса» исключение КФХ проверено по первой странице 622-П, новая редакция п. 6. Тест подтверждает FAIL для КФХ и UNKNOWN при отсутствии подтверждённых остальных условий.
- Для семейного фермерского гранта КФХ — необходимый признак; он **не достаточен**: семейный состав, территория и проект дают ручную проверку UNKNOWN.
- Для «Агромотиватора» синтетическое поле `special_category` не используется. Специальная категория проверяется вручную по 770-П/623-П; нельзя считать любой флаг льготы доказательством участия в программе.
- Кооператив — отдельная организационная форма. Уточнение вида и состава кооператива обязательно.
- У компенсаций кадровых затрат проверяются ИП/организация и понесённые расходы; конкретное назначение расходов и территория требуют подтверждения.
- Неподдерживаемые анкетой юридические условия представлены безопасным оператором `manual`, всегда возвращающим UNKNOWN. Пустой набор правил тоже даёт UNKNOWN. Произвольный код не исполняется.
- Поле `verified_at` оставлено пустым; `research_checked_at` — дата исследования, не дата полной проверки. Неизвестный период нормативной применимости не заменяется сроком отбора.

## Как завершить редакторский проход

1. Открыть локальное приложение → вход редактора → «Реальные меры». Для каждой карточки видны пробелы, применимая редакция и ссылки.
2. Сверить полный сводный текст с отдельными поправками и объявлением конкретного отбора; сохранить точные пункты и дату официального опубликования каждого акта. Сверить действующий статус на портале.
3. Уточнить документы по категориям заявителей, обязательства, исключения, размер и условия финансирования. Предварительные перечни в черновиках не являются исчерпывающей инструкцией подачи.
4. Устранить `missing_evidence`; заполнить период применимости, `verified_at`, статус источников. Ручные условия можно оставить только как явно обозначенную проверку документов, а не пробел в исследовании нормативной базы.
5. Сохранить → «На проверку» → «Опубликовать». Публикация не выполняется импортом. Новые данные источника оформлять новой версией; существующие планы сохраняют старую.

## Воспроизведение

Из корня: `docker compose exec -T app python backend/import_official.py` — валидация; с `--apply` — добавление только отсутствующих мер как черновиков. Повторный запуск сохраняет все существующие меры и пользовательские изменения. Для обновления уже импортированной меры используйте новую версию в редакторе, а не повторный импорт.

Источники загружены вручную в рамках исследования. Периодический автоматический импорт и автоматическая содержательная актуализация не реализованы. Правила черновиков проверены частично; полное соответствие всем первоисточникам не заявляется.
