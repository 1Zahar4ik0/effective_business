## Исправленная ошибка подбора

Старый черновик требовал is_kfh=true без исключений. Базовый 181-П, п. 8а,
допускает для проектов по абзацам 2–3 п. 7 гражданина РФ с обязательством
зарегистрировать КФХ / ИП — главу КФХ в течение 30 календарных дней после
решения комиссии. Объявление содержит такое обязательство на стр. 3 и 11.
Поэтому is_kfh=false у физлица не доказывает несоответствия.

Теперь организационная форма проверяется отдельно; регистрация, исключение,
семейный состав и территория остаются UNKNOWN до проверки документов.
Кооператив получает FAIL по форме. Анкета без сведений — UNKNOWN.
Результат не означает предоставление права на грант.

## Конфликты, блокирующие публикацию

   исключением п. 8а необходимо уточнить по действующей карточке / у министерства.
2. Стр. 9–10 объявления содержат разные списки исключений для прежней поддержки.
   624-П, стр. 3, добавляет исключения для Агротуризма, малой сельской пекарни
   и акселерации молочной фермы. Старый список не используется для отказа.
3. Стр. 6 объявления сначала допускает простую подпись подтверждённой учётной
   записи физлица, затем требует УКЭП в общей формулировке.
4. Не завершены проверка актуальной редакции, общих ограничений, критериев
   конкурса, приложений и портальной карточки.
