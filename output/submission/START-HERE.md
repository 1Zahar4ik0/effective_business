# Опора АПК: комплект перед сдачей

Версия: `opora-apk-20260918-local-r1`. **Это проверенная локальная демонстрация; допуск по требованию живого MAX пока заблокирован.**

- `public/` — публичные PPTX/PDF, сценарий выступления. Без реальных токенов и закрытых доступов.
- `jury/` — отдельная презентация с техническим первым слайдом, инструкции проверки, OpenAPI, DATA-API и тестовые данные. Эта папка предназначена для жюри.
- `source.zip` — исходники, документация, миграции, фиксированные зависимости и подготовленные источники. `.env`, приватные ключи и база данных исключены.
- `VERSION.json`, `SHA256SUMS.txt` — идентификатор версии и контрольные суммы.

## Локальная демонстрация

Распаковать `source.zip` в отдельную папку. Если на этом компьютере уже запущен основной стенд, не запускать вторую копию на тех же портах. Из папки исходников выполнить:

```powershell
docker compose up -d --build
```

Открыть http://localhost:8000. Войти как фермер, заполнить учебный пример, выполнить подбор, открыть карточку, сохранить план и отметить документ. После перезагрузки открыть «Мои планы». Выйти и войти редактором для осмотра реальных черновиков. Для их загрузки на новой базе:

```powershell
docker compose exec -T app python backend/import_official.py --apply
```

Импорт не публикует меры и не переписывает существующие записи. В свежем демо сначала видны только шесть синтетических мер. Тестовые профили — `data/demo/profiles.json` внутри исходников.

## Перед отправкой организаторам

1. Настроить разрешённое размещение с доверенным HTTPS, MAX бот и мини-приложение. Заполнить реальный адрес API и выдать необходимые роли проверяющим.
2. Пройти основной путь в мобильном и веб-MAX, добавить фактический отчёт. Локальная ширина 390 px этого не заменяет.
3. Заполнить состав команды. Сверить формат DATA-API с фактическим шаблоном платформы оценки.
4. Завершить проверку реальных условий либо явно согласовать демонстрацию на подготовленных/синтетических данных согласно заданию.
5. Секреты передать отдельно по защищённому каналу. Не добавлять их в публичные материалы, исходники или чат.

После изменения исходников/материалов собрать **новую версию** с новой контрольной суммой. После дедлайна переданный архив не изменять. Этот комплект никуда не отправлен автоматически.
